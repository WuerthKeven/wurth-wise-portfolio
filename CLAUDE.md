# WISE Portfolio

Static site: `index.html` + `assets/`, edited directly in this repo (no build, no Claude Design sync).
It is presented by double-clicking `index.html`, so every link must be a relative path to a file.

To add or update a solution's detail (card/modal text, promo page, platform link, preview video),
use the project skill `add-project-detail` (`.claude/skills/add-project-detail/`). The Creative
Platform (`creative`) is the reference; don't invent a new pattern per project.

Work on a branch and open a Pull Request; never push to `main`.
